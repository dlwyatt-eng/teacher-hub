Decimal thinking · visual support

Keep the whole the same

Compare tenths and hundredths using equal wholes.

Each complete grid is 1 whole. Each small square is 1 hundredth. Point, speak, draw or write.

Look at the example

The first grid shows 40 hundredths: 0.40, or 4 tenths. The second shows 4 hundredths: 0.04. Forty hundredths is greater than four hundredths, so 0.4 > 0.04.

1. Compare 0.6 and 0.60. Point to evidence in the grids. Explain your choice.

Number comparison · oral support

Point to the place that decides

Compare from the greatest place and explain the first difference.

Read each row from left to right. Point to matching places, then the first place that differs.

Look at the example

Compare 4.305 and 4.35. Write 4.35 as 4.350; its value stays the same. The ones and tenths match. The hundredths first differ: 0 < 5. So 4.305 < 4.35.

Quantity comparison · teacher-selected goal

Match the two collections

Compare collections by matching or counting each dot once.

Match one left dot with one right dot. You can draw matching lines, point, or use counters. Check for any dots without a partner.

Look at the example

There are 3 dots on the left and 5 on the right. Make 3 pairs. Two right dots have no partner, so the right collection has more. The left collection has fewer.

1. Match or count. Which collection has more? Show how you know.

  • Left
  • Right
  • Same amount

2. Which collection has more now? Match or count to check.

  • Left
  • Right
  • Same amount

Words you can use

This collection has more.

These dots do not have a partner.

Quantity comparison · fresh check

More, fewer or the same?

Compare new collections, including equal amounts.

Use matching or counting. Point to a choice and show your reason. Work on each new pair before someone tells you an answer.

Look at the example

The model has 2 dots on each side. Every dot has a partner and none are left unmatched. The collections have the same amount.

1. Which collection has more? Show your comparison.

  • Left
  • Right
  • Same amount

2. Which collection has fewer? Point, then check.

  • Left
  • Right
  • Same amount

3. Do these collections have different amounts or the same amount? Show how you know.

  • Different amounts
  • Same amount

Words you can use

I matched ___.

This side has fewer.

Every dot has a partner.

Optional · represent numbers to 40

Groups of ten and loose ones

Connect groups of ten and single ones to a written number.

Each long rod contains 10 small units. Each loose square is 1. Count groups and loose ones.

Look at the example

The model has 2 tens and 3 ones. Two groups of ten and three loose ones make 23. This is a representation of 23, not an addition or subtraction task.

1. How many tens? How many ones? Say or write the number shown.

2. Which collection shows the greater number? Use the tens and ones to explain.

3. Fresh try: name the tens, the ones and the number. What does the empty ones space mean?

Words you can use

I see ___ tens and ___ ones.

The number is ___.

Optional · join and take away within 10

Show what changes

Represent joining and removing objects, then find the amount.

One dot is one object. Use the frame, draw, or move counters. Add dots when joining; cross out or remove dots when taking away.

Look at the example

Outlined dots are added; crossed dots are removed. First frame: start with 4 dots and add 2. There are 6: 4 + 2 = 6. Second frame: start with 6 dots and remove 3. There are 3 left: 6 − 3 = 3.

1. Start with 2 dots. Add 5 more. How many altogether? Show the joining.

2. Start with 9 dots. Take away 4. How many remain? Show what was removed.

3. Fresh try: start with 3 dots and add 5. Show the change and the total.

4. Fresh try: start with 8 dots and take away 1. Show how many remain.
