# Homework and optional home practice

Teacher Hub content/home-practice.json is the canonical student-safe home-practice source. Keeping it separate avoids loading the full menu on the Teacher Hub landing page. The existing sync:public-window command projects it into public/generated/public-window-v2.json; copy that file to Learn app/generated/public-window-v2.json. Learn renders #/homework. Teacher Hub Classroom Guide > Homework reviews the same source on demand.

When teaching changes, archive the outgoing week under content/home-practice/YYYY-MM-DD.json and edit the current menu. Confirm what was actually taught rather than treating a day plan as a completion record. Retain examples, short tasks, checking guidance and screen-free access. Individual tasks, adaptations and deadlines remain private. Preserve class-account uncertainty until details are confirmed. Run both repository gates, check navigation and print, then publish both repositories from current main.

The dated menu becomes Latest published practice outside its date range. This change does not create another scheduler or automatically publish device-local plans. Optional activities require no purchase or routine SpacesEDU uploads. Existing school dates, portfolio setup status and rights resources are retained.

Release scope: structured opening-week practice; no claims that all subjects have been taught. The print button expands all activities and excludes checking guidance unless selected. Physical printing and classroom comprehension still need user feedback.
