# Daily materials, Korean support and tentative plans

## Prepare one day

1. Open the dated Shape of the Day, then choose **Edit this day**. The selected day opens in the existing Day Plans editor; opening another saved plan keeps its date in the URL.
2. If this is an automatic Weekly Plan snapshot, copy it to the same teaching date first. Later Weekly Plan saves rebuild automatic snapshots; the explicit dated copy keeps your day-only choices and the original stays in history.
3. In each block, keep the activity title and a short first student action. Teaching steps stay in the teacher plan; projector steps are student-facing.
4. Expand **Choose today’s material / student worksheet**. Give each selected resource a clear label and the exact URL. Preview it, check its access and contents, and mark it student-safe only when it contains no private notes or answers. Changing its URL removes that approval. No files are uploaded or permissions changed.
5. Keep **Full lesson / reference** as an optional student-safe route. A subject home or full workshop is not the same as a chosen worksheet. The board labels them separately.
6. Optional Korean title and first-action text are manual pairs. English stays visible. Changing the English title or first action clears only its paired Korean text so stale translations are not silently shown.
7. Save or allow autosave, then project the day. The board's English + 한국어 toggle is off by default and remembers its setting on this browser. Missing Korean text leaves the English intact.

## Links and privacy

- Use ordinary HTTPS destinations, existing Hub query routes, or a relative site PDF/HTML path such as `./printables/example.pdf`. Only link to material you have permission to use and share with the intended audience.
- The URL check blocks executable schemes, protocol-relative paths, path traversal, control characters, embedded credentials and common signed/token-bearing download URLs. It does not determine a resource's licence, audience, or permissions; the preview and student-safe approval remain necessary.
- Student materials must not contain pupil data, private answer keys or temporary Library download URLs. Use the original approved resource service when a sign-in is required. Do not copy licensed files into this public repository.
- Teacher reference URLs and page/answer-key notes are for browser-created revisions only. They are never included in published day-plan JSON, student/projector rendering or the family learning summary. A test enforces the published-JSON boundary.
- Teacher references are included in a downloaded JSON backup and a teacher printout. Those files must be kept with your teaching files, not shared as student worksheets. Teacher-only display is not access control. Do not enter confidential pupil records, passwords, access tokens or secret download links anywhere in the Hub.
- Changes, revisions and the Korean preference stay on this browser. They are not cloud-synced. Keep the existing JSON backup/import workflow when moving devices. Imports validate the entire batch before saving and reject conflicting revision IDs, including conflicts inside one file.

## Print the intended thing

**Print teacher day plan** prints the dated teaching plan: arrival, first actions, teaching and student steps, chosen material links, optional full lesson references, teacher page notes, backups and reflections. It does not embed or silently print a linked worksheet.

For student copies, choose **Open worksheet to print**, confirm the chosen student file, and use its print controls. Existing lesson **Print student workshop** controls still print their workshop; they are separate from the daily worksheet selection.

## Plan ahead without implying confirmation

Plans with `status: "tentative"` show **Tentative plan · review before teaching** on the board and teacher printout, with a tentative label in the archive. Tentative plans are excluded from automatic date selection; explicitly choose one to review or project it. The editor's tentative checkbox can be cleared after the teacher reviews the plan. Dates, revisions and earlier plans are retained; the status does not assert that a lesson has happened. Tentative planning does not update the confirmed family summary or create calendar events.

The Oct 1 and Oct 2 plans retain their existing timing, sequence and materials. Their new bilingual starts are short suggested student directions; they do not invent a Nevermoor chapter, a worksheet attachment, or an activity that the source did not specify.
