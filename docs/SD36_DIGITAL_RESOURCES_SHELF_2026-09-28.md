# Later this week: SD36 Digital Resources shelf

Created: 2026-09-28

## Goal

Add a compact, teacher-facing shelf in Teacher Hub for Surrey Schools digital resources that are already available through district access. Do not build a second curriculum system. Link the right tool at the point of use and keep Student Hub links limited to resources students can actually access safely.

## Source pages to verify before publishing

- Surrey Schools Student Resources: https://www.surreyschools.ca/learningresourcesservices/student-resources
- Surrey Schools Digital Resources / password handouts: https://www.surreyschools.ca/learningresourcesservices/digital-resources-password-handouts

## Priority connections

1. **myBlueprint** → Career Education, especially career connections emerging from Be the Change Action Packs.
2. **InfoLaunch** → Grade 6 research, source notes, and citation practice.
3. **Sora / World Book Student** → reading and inquiry support.
4. **NFB Education, CBC Curio, ClickView/TWIG, Live It Earth, Surrey Public Libraries teacher access** → teacher-curated media and inquiry sources where district access is confirmed.

## Build constraints

- Verify current district access and sign-in instructions before surfacing a resource.
- Never publish passwords, join codes, student account details, or staff-only credentials.
- Prefer contextual links inside Career, ELA, Science/Social Studies, and Newsroom rather than a giant undifferentiated link dump.
- Keep Teacher Hub canonical; add public links to Learn only when they are genuinely student/family useful.
- Mark resources that require teacher launch or district authentication.
- No broad redesign for this task.
